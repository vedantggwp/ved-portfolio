   - Use only chromium for speed (can expand later)
   - Set `baseURL: 'http://localhost:3000'`

3. Create `tests/scaffold.spec.ts` with these tests (tag @smoke):

   **Test: "dark background and fonts"** (FOUND-01)
   - Navigate to '/'
   - Assert body computed background-color is rgb(10, 10, 10) (#0A0A0A)
   - Assert body computed font-family contains "Inter" or the sans-serif fallback
   - Find an h2 element (visually-hidden headings from SectionShell)
   - Assert h2 computed font-family contains "DM Serif Display" or the serif fallback

   **Test: "SSR safe - no hydration errors"** (FOUND-06)
   - Listen for console errors during page load
   - Navigate to '/'
   - Wait for page to be fully loaded
   - Assert no console errors containing "hydration" or "mismatch"

   **Test: "all sections rendered"**
   - Navigate to '/'
   - Assert 8 section elements exist
   - Assert sections appear in correct order by checking IDs: surface, transition-1, pocket-1, pocket-2, pocket-3, transition-2, projects, contact

4. Create `tests/a11y.spec.ts` with these tests:

   **Test: "reduced motion - CSS kills animations"** (A11Y-01, FOUND-05)
   - Use `page.emulateMedia({ reducedMotion: 'reduce' })`
   - Navigate to '/'
   - Create a test element with a CSS animation
   - Assert its computed animation-duration is "0.01ms" (from the media query override)

   **Test: "keyboard navigation"** (A11Y-02)
   - Navigate to '/'
   - Press Tab repeatedly
   - Assert focus moves to skip links first (they become visible on focus)
   - Assert skip links are visible when focused (check computed position/top)
   - Assert focus order follows DOM order

   **Test: "ARIA landmarks"** (A11Y-03)
   - Navigate to '/'
   - Assert section#surface has role="banner"
   - Assert section#contact has role="contentinfo"
   - Assert pocket sections have aria-label attributes
   - Assert transition sections have role="presentation"
   - Assert non-transition sections have visually-hidden h2 headings

   **Test: "skip links"** (A11Y-04)
   - Navigate to '/'
   - Tab to first skip link ("Skip to projects")
   - Press Enter
   - Assert focus is now on #projects section (document.activeElement check)
   - Tab to second skip link ("Skip to contact")
   - Press Enter
   - Assert focus is now on #contact section

   **Test: "contrast meets WCAG AA"** (A11Y-05)
   - Navigate to '/'
   - Get computed color and background-color of body
   - Calculate contrast ratio programmatically (luminance formula)
   - Assert ratio >= 4.5 (AA requirement for normal text)
   - Get computed color of an element using --color-accent
   - Calculate its contrast ratio against background
   - Assert ratio >= 4.5

   **Test: "focus styles"** (A11Y-06)
   - Navigate to '/'
   - Tab to a skip link
   - Assert the focused element has an outline (computed outline-style is not "none")
   - Assert outline color is amber (#C4964A) or equivalent rgb(196, 150, 74)
   - Assert outline-width is 2px

Each test should have a descriptive name matching the grep patterns from RESEARCH.md Validation Architecture.

<task type="auto">
  <name>Task 2: Fix any gaps found during testing</name>
  <files>
    src/app/globals.css

  <action>
Run the full Playwright suite. For any failures:

1. **Contrast failures:** If computed contrast ratio is below 4.5:1, adjust the specific color in globals.css. The amber accent (#C4964A) should be 7.36:1 on #0A0A0A per research -- if tests show otherwise, adjust the hex value upward in lightness while maintaining warm amber hue.

2. **Focus ring not visible:** If outline is not rendering, check that `:focus-visible` is correctly applied in globals.css. Ensure the `.skip-link:focus` style also applies the custom outline (not just position change).

3. **Skip link focus not moving:** If pressing Enter on skip link doesn't move focus to target, verify the target section has `tabindex="-1"`. If missing, update SectionShell component (but that file belongs to plan 01-01 -- if this is the case, add a targeted fix to globals.css using `:target` pseudo-class or note it as a gap for 01-01 SUMMARY).

4. **Reduced motion test failing:** If animation-duration override doesn't apply, check that the `@media (prefers-reduced-motion: reduce)` block in globals.css uses `!important` and targets `*, *::before, *::after`.

5. **Hydration mismatch:** If SSR test catches a mismatch, verify that useReducedMotion initializes to `false` (not reading matchMedia during SSR).

After fixes, re-run the full suite to confirm all green. Run twice to confirm no flakiness.

If ALL tests pass on first run with zero fixes needed, this task is a no-op -- document "all tests passed, no fixes required" in the summary.
