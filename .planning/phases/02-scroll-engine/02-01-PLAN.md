  <name>Task 1: Install dependencies and create scroll store + physics config</name>
  <files>package.json, src/lib/scroll-store.ts, src/lib/scroll-physics.ts, tests/scroll.spec.ts</files>
  <action>
    1. Install dependencies: `npm install lenis gsap @gsap/react`

    2. Create `src/lib/scroll-store.ts` -- mutable scroll value singleton:
       - Export a `ScrollValues` type: `{ progress: number, velocity: number, direction: number, section: string, sectionProgress: number }`
       - Export `scrollStore` as a mutable singleton object with defaults (progress: 0, velocity: 0, direction: 1, section: 'surface', sectionProgress: 0)
       - Export `updateScrollStore(partial: Partial<ScrollValues>)` that uses Object.assign to mutate the singleton and notifies listeners
       - Export `onScrollChange(fn: (values: ScrollValues) => void): () => void` -- adds listener, returns unsubscribe function
       - Export `resetScrollStore()` for testing -- resets to defaults
       - Listener array is module-scoped, NOT exported
       - CRITICAL: This is intentionally mutable. No React state, no useState, no zustand. Consumers read via refs or rAF loops.

    3. Create `src/lib/scroll-physics.ts` -- per-section ScrollTrigger config:
       - Export `ScrollPhysicsConfig` type: `{ end: string, scrub: number, pin: boolean }`
       - Export `SCROLL_PHYSICS` as a `Record<string, ScrollPhysicsConfig>` keyed by section ID from SECTIONS
       - Values per user decisions (content-proportional durations):
         - surface: `{ end: '+=100vh', scrub: 1, pin: true }` (1x -- brief hook)
         - transition-1: `{ end: '+=50vh', scrub: 0.5, pin: false }` (0.5x -- passage)
         - pocket-1: `{ end: '+=150vh', scrub: 1.2, pin: true }` (1.5x -- reading)
         - pocket-2: `{ end: '+=150vh', scrub: 1.2, pin: true }` (1.5x)
         - pocket-3: `{ end: '+=150vh', scrub: 1.2, pin: true }` (1.5x)
         - transition-2: `{ end: '+=50vh', scrub: 0.5, pin: false }` (0.5x -- passage)
         - projects: `{ end: '+=200vh', scrub: 1.5, pin: true }` (2x -- discoveries)
         - contact: `{ end: '+=75vh', scrub: 1, pin: false }` (0.75x -- payoff)

    4. Create `tests/scroll.spec.ts` -- e2e test scaffold for all Phase 2 requirements:
       - Import from `@playwright/test`
       - Create test group: `test.describe('Scroll Engine', () => { ... })`
       - Tests to create (stubs that will be filled as features land):
         a. "smooth scroll -- Lenis initializes and page scrolls": Navigate to page, verify `html` element has class `lenis` (Lenis adds this). Scroll with `page.mouse.wheel(0, 500)`, wait briefly, verify scroll position changed.
         b. "no rerender -- scroll store does not use React state": Use `page.evaluate` to check `window.__SCROLL_STORE_READS__` counter (exposed in dev mode via ScrollEngine). Scroll, then verify counter is 0 (no React re-renders from scroll).
         c. "section order -- depth-based sections in DOM": Query all `section` elements, verify IDs match expected order: surface, transition-1, pocket-1, pocket-2, pocket-3, transition-2, projects, contact.
         d. "progress -- scroll store exposes 0-1 progress": Scroll to bottom, use `page.evaluate` to read `window.__scrollStore.progress`, verify it approaches 1.
         e. "pin -- content sections pin during scroll": Scroll to pocket-1, verify it stays in viewport (getBoundingClientRect().top near 0) across additional scroll increments.
       - Helper function: `scrollToSection(page, sectionId)` using `page.evaluate` to scroll element into view
       - Expose scroll store on window in ScrollEngine (dev only) for test access: `if (typeof window !== 'undefined') { (window as any).__scrollStore = scrollStore }`

       - Add `React.forwardRef<HTMLElement, SectionShellProps>` wrapper
       - Pass `ref` to the `<section>` element
       - Keep all existing ARIA, role, tabIndex, and heading logic unchanged
       - Add `children` prop: `readonly children?: React.ReactNode` -- sections will soon have content

    3. Create `src/components/ScrollEngine.tsx` -- 'use client' component:
       - Import Lenis, gsap, ScrollTrigger, useGSAP from @gsap/react, useReducedMotion, scrollStore, updateScrollStore, SCROLL_PHYSICS, SECTIONS
       - Register ScrollTrigger plugin: `gsap.registerPlugin(ScrollTrigger)`
       - Accept `{ children: React.ReactNode }` props
       - Gate everything on `useReducedMotion()` -- if reduced motion, render children without Lenis/GSAP
       - In `useEffect` (not useGSAP -- Lenis init is not a GSAP animation):
         a. Create Lenis instance: `new Lenis({ lerp: 0.1, duration: 1.2, smoothWheel: true })`
         b. Sync Lenis -> ScrollTrigger: `lenis.on('scroll', ScrollTrigger.update)`
         c. Sync GSAP ticker -> Lenis: `gsap.ticker.add((time) => { lenis.raf(time * 1000) })`
         d. Disable GSAP lag smoothing: `gsap.ticker.lagSmoothing(0)`
         e. Update scroll store on each scroll: `lenis.on('scroll', ({ progress, velocity, direction }) => { updateScrollStore({ progress, velocity, direction }) })`
         f. Expose scroll store on window for tests: `(window as any).__scrollStore = scrollStore`
         g. Cleanup: destroy lenis, remove ticker callback, kill all ScrollTriggers
       - In `useGSAP` (for ScrollTrigger instances, which are GSAP animations):
         a. For each section in SECTIONS, look up its physics config from SCROLL_PHYSICS
         b. Create a ScrollTrigger for each section: `ScrollTrigger.create({ trigger: '#' + sectionId, start: 'top top', end: config.end, pin: config.pin, scrub: config.scrub, onUpdate: (self) => updateScrollStore({ section: sectionId, sectionProgress: self.progress }) })`
         c. Use CSS selector `'#' + sectionId` for trigger (section IDs are on the DOM elements)
         d. IMPORTANT: Do NOT pin sections that have `pin: false` in config (transitions, contact)
         e. Debounced resize handler that calls `ScrollTrigger.refresh()` after resize settles (200ms debounce)
       - Render: `<>{children}</>`

         ```
         </body>
         ```
