  <name>Task 1: Create GLSL shaders and uniform definitions</name>
  <files>src/three/MonolithShader.ts</files>
  <action>
  Create `src/three/MonolithShader.ts` with:

  1. **Uniform definitions** (exported as a function that creates fresh uniform objects):
     - `uTime: { value: 0 }` -- elapsed time for animation
     - `uMorphProgress: { value: 0 }` -- scroll-driven morph (0-1)
     - `uRimColor: { value: new THREE.Color(1.0, 0.6, 0.1) }` -- amber
     - `uRimPower: { value: 3.0 }` -- fresnel falloff exponent
     - `uRimIntensity: { value: 1.5 }` -- fresnel strength multiplier

  2. **Vertex shader** (exported as string):
     - Include Ashima simplex 3D noise (snoise) -- embed the full GLSL function (~60 lines from webgl-noise repo). Do NOT use an external import or glslify.
     - Taper the top of the box to create obelisk shape: heightNorm = (pos.y + 1.5) / 3.0, taper = 1.0 - heightNorm * 0.65
     - Scroll-driven morph: sample snoise at (pos * 2.0 + uTime * 0.1), multiply by uMorphProgress * 0.3, displace along normal
     - Cap effective morph at 0.85 of uMorphProgress for displacement (MONO-05 -- never fully resolved). Use `min(uMorphProgress, 0.85)` for the primary displacement layer.
     - Add a secondary high-frequency noise layer: snoise(pos * 8.0 + uTime * 0.05) * uMorphProgress * 0.05 -- this adds detail that hints at hidden internal structure even at max morph.
     - Compute displaced normals via finite difference method: sample noise at pos + small epsilon in tangent and bitangent directions, cross product gives corrected normal. This is critical for correct fresnel on deformed geometry.
     - Pass varyings: vNormal (corrected), vViewPosition, vDisplacement

  3. **Fragment shader** (exported as string):
     - Fresnel rim: `rim = 1.0 - max(0.0, dot(normal, viewDir))`, raised to uRimPower, multiplied by uRimIntensity and uMorphProgress
     - Base color: dark warm `vec3(0.05, 0.04, 0.03)`
     - Add faceting detail: mix in displacement-based brightness `vec3(vDisplacement * 0.5) * uMorphProgress`
     - Add non-uniform face variation: use a low-frequency noise based on world position to make some faces more displaced than others (contributes to the "unseen geometry" feel)
     - Final color = baseColor + rimColor * rim
     - Output with alpha 1.0

  Export: `createMonolithUniforms()`, `monolithVertexShader`, `monolithFragmentShader`
